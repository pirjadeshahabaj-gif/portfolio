# Shahabaj Pirjade | AI/ML Portfolio

A responsive personal portfolio website for Shahabaj Pirjade, focused on artificial intelligence, machine learning, data analysis, and software engineering.

## Overview

The portfolio presents:

- An AI/ML engineering introduction and career highlights
- About section covering machine learning, analytics, and software engineering strengths
- Featured projects in machine learning, NLP, analytics, and web development
- Core technologies and applied capabilities
- IBM Big Data and Business Management internship experience
- Contact and availability information

## Featured Projects

- **Fraud Detection System**: Machine learning system for identifying suspicious patterns and reducing financial loss.
- **Text Intelligence**: NLP workflow for extracting insights from unstructured content.
- **Decision Dashboard**: Interactive reporting experience for tracking metrics and trends.
- **Food Munch Website**: Responsive food discovery website deployed with GitHub Pages.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Dark, glass-inspired visual design with animated background elements

- Automatically updated copyright year
- No external dependencies or build process

## Run Locally

Because this is a static website, it can be opened directly in a browser:

1. Open `index.html` in a web browser.

For a local development server, run one of these commands from the project directory:

```bash
# Python
python -m http.server 8000
```

Then visit https://pirjadeshahabaj-gif.github.io/portfolio/
